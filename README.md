# غذای هوشمند 🌿
اپلیکیشن دستور پخت فارسی با رابط راست‌به‌چپ.

## اجرا
```
flutter pub get
flutter run
```

## ساخت APK
```
flutter build apk --release
```

## ساختار
- `lib/theme`: تم متریال ۳ و رنگ‌ها (#1E4D38 و #F9F7EE)
- `lib/models`: مدل‌های Ingredient، Recipe، UserPrefs و SchoolLunchProfile
- `lib/data`: مواد اولیه، دستورها و گزینه‌های چاشت (`school_lunch_data.dart`)
- `lib/services`: ذخیره‌سازی SharedPreferences، پیشنهاد دستورها و فیلتر/رتبه‌بندی چاشت (`school_lunch_service.dart`)
- `lib/screens`: صفحه‌ها از جمله `SchoolLunchScreen` و فرم پروفایل چاشت

## چاشت مدرسه
از کارت «چاشت مدرسه» در خانه وارد شوید. پروفایل محلی شامل سن ۳ تا ۱۸ سال، نام اختیاری، جنسیت (فقط برای نمایش/زمینه کلی سنی)، پسندها، موارد نامطلوب، آلرژی/عدم‌تحمل، محدودیت غذایی، قوانین مدرسه و امکان گرم‌کردن است. پیشنهاد روزانه و چرخش هفتگی فقط از گزینه‌های باقی‌مانده پس از حذف آلرژی‌ها، موارد نامطلوب، محدودیت‌ها و غذاهای ناسازگار با گرم‌کردن ساخته می‌شود؛ اگر موردی باقی نماند، صفحه صریحاً نبود پیشنهاد را اعلام می‌کند. نیاز انرژی فردی از جنسیت استنباط نمی‌شود.

این پیشنهادها ایده‌های عمومی هستند، نه برنامه غذایی یا توصیه پزشکی. والدین باید ترکیبات و احتمال آلودگی متقاطع، قوانین مدرسه و نگهداری ایمن غذا را بررسی کنند؛ برای نیاز ویژه با پزشک کودک/متخصص تغذیه مشورت شود. آماده‌سازی و اندازه لقمه باید با سن کودک متناسب باشد.

## کنترل کیفیت
پروژه برای اجرای محلی به Flutter 3.x و Dart 3 نیاز دارد. اگر SDK در محیط توسعه در دسترس باشد، `flutter analyze` و سپس `flutter test`/`flutter build` اجرا کنید.

## ساخت اندروید و Gradle
تنظیمات Android Gradle Plugin 8.3.2، Gradle 8.4 و Java 17 با هم سازگارند. فایل‌های wrapper اجرایی و `local.properties` عمداً داخل zip نیستند: مسیر Flutter SDK روی هر رایانه متفاوت است و wrapper باید با Flutter/Gradle نصب‌شده محلی ساخته شود. دستورهای زیر را از ریشه پروژه اجرا کنید:

```sh
flutter pub get
cd android
gradle wrapper --gradle-version 8.4 --distribution-type bin
cd ..
flutter analyze
flutter build apk --release
```

در GitHub Actions، Gradle 8.4 نصب و wrapper به‌صورت خودکار ساخته می‌شود؛ سپس APK نهایی به‌عنوان artifact منتشر می‌شود.
